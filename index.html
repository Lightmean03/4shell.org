About

Why "4Shell" and "2Shell"?

Log4Shell (December 2021) took its name from "Log4j" plus "shell": one log line gave an attacker a shell. Spring4Shell and Text4Shell followed in 2022. In December 2025, React2Shell switched to "2Shell" ("React to shell"), and the 2026 wave of PHP2Shell, Node2Shell, wp2shell and others kept that form. Most of these names are informal, so always check the CVE IDs.

What gets listed

A bug is listed when it has a CVE, a widely used *4Shell / *2Shell name, and coverage from at least one reputable source. Famous relatives whose name also ends in "Shell" (Shellshock, ProxyShell, ToolShell…) are included as related entries.

About the PoC links

Proof-of-concept links point to third-party code that hasn't been audited. Fake "PoC" repos that install malware show up within hours of every big CVE. Read the code before you run it, run it only in an isolated lab, and test only systems you're authorized to test.

Found a new one, a dead link, or a better PoC? Every entry lives in data/vulns.json. Open an issue or a pull request.
